# 04 — 知覚 (集音 / 話者分離 / センサ / 状況)

**スコープ**：外界を取り込む。遠方の音声を拾い、誰の発話か分けてラベル付けし、各種センサと合わせて
「今どういう状況か」を推定する。ただし **認識は絶対でない**（D4）。音声土台は
[voice-realtime-design](../../api/voice-realtime-design.md)（StreamAudioTranscription）。

## 現時点の知見

### 音声：集音 → 話者分離 → ラベル付け

```
遠方の音声
 → ① 入力ゲイン増幅 / ノイズ抑制         (前処理, 非LLM)
 → ② 話者分離 (diarization)              「誰が」区切る
 → ③ 音量正規化 (各話者ごと)
 → ④ 各話者を文字起こし                   StreamAudioTranscription
 → ⑤ 会話内容から役割推測 → ラベル付け     軽量モデル(T0/T1)
```
- ①〜③は**非LLMの信号処理**（安い）。ここで質を上げると文字起こし精度が効く。
- ラベル付けは「発話内容・呼びかけ・声紋の再出現」から人物/役割を推測 → 記憶の人物ノードへ紐付け（確信度付き）。
- **未検証**：`StartAudioTranscriptionRequest` は単一ストリーム前提に見えるので、**話者分離は前段（外部）**に置くのが安全。実機で要確認。

### 状況認識（マルチセンサー推定）

- 入力：PC状態（起動タスク/ディスク/前面アプリ）、座標(GPS)、時刻、温度・明るさ、会話インデックス。
- モデルに状況を推定させる（例「在宅・作業中・来客あり」）。出力は状況ラベル＋確信度 → [01-kernel](../01-kernel/) 監視ループの入力。

### 不確実性の原則（D4, 重要）

- 推定は常に**確信度付き**。閾値未満は「確定情報として扱わない」。
- 確定が要る場面は**確認を取る**か、低確信フラグ付きで保持し行動を保留。
- 記憶に書くとき `confidence` と `source`（どのセンサ/発話由来か）を必ず添える → 訂正可能・説明可能。
